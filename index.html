Stack

What each layer is responsible for.

Layer Tool Purpose
App Streamlit Live company runner and query interface.
Ingestion Python Discovery, crawling, parsing, validation, and Snowflake loading.
Warehouse Snowflake Raw public pages and analytics outputs.
Modeling dbt Core + dbt Snowflake Staging models, marts, and tests.
Discovery Tavily Company lookup and related-site search.
Optional ops Fivetran, Stripe, Vercel, Compass backend Operational metadata sources when configured.

Runtime

GitHub Pages is the portfolio page. Streamlit runs the app.

This static page is safe to share publicly. The live workflow needs a Python runtime plus secrets for Snowflake, Tavily, and optional AI providers, so it belongs on Streamlit Community Cloud or another secure runtime.

Local setup

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env

Run analysis app

python scripts\validate_environment.py
python scripts\crawl_websites_to_snowflake.py --bootstrap-only
streamlit run app\streamlit_app.py
